# Skill description attribution

Material icons are original Nexon game assets served by MapleStory Wiki: [Sol Erda](https://maplestorywiki.net/w/File:Use_Sol_Erda_(Full_Size).png) and [Sol Erda Fragment](https://maplestorywiki.net/w/File:Etc_Sol_Erda_Fragment_(Full_Size).png). Local copies preserve the original images; their game artwork remains owned by Nexon.

Skill descriptions and level effects in `descriptions.js` are adapted from [MapleStory Wiki](https://maplestorywiki.net/w/Characters_and_Skills), retrieved through its public MediaWiki API on September 10, 2026. Each skill record retains a direct source URL, also linked in the interface.

Wiki text is provided under [Creative Commons Attribution-NonCommercial-ShareAlike 3.0](https://creativecommons.org/licenses/by-nc-sa/3.0/). The adapted description dataset is distributed under that same license. These terms apply to the wiki text, not a claim of ownership over MapleStory or Nexon game assets.

Changes: HTML was converted to plain text, duplicate min/max and full-level tables were merged, skills were grouped by their wiki HEXA node, and matching descriptions were attached to planner node IDs. Related mastery skills are displayed together. Boost nodes include their corresponding V skill's description when matched, with the HEXA enhancement's level effects. No V skill damage is inferred from a HEXA level.

The snapshot includes 53 class skill pages and descriptions matched to 516 class-specific nodes, plus shared Sol Janus and Sol Hecate skills. Third common and third skill node descriptions are intentionally unavailable. Erel's placeholder source names and Kinesis's unmatched fourth boost node are left unavailable; Lethe's wiki skill page was unavailable at collection time. The source class-page link is still provided. Descriptions can reflect different regional patches from the planner's English labels.

Locked nodes preview level 1. Matrix and skill-list descriptions use current levels; roadmap descriptions use milestone target levels. If an exact level's effects are absent, the UI says so rather than estimating them.
